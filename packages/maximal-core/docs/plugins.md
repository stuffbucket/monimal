# Plugin Integrations

- **Claude Code plugin:** Install from marketplace with `/plugin marketplace add https://github.com/caozhiyuan/copilot-api.git` then `/plugin install agent-inject@copilot-api-marketplace`. Injects `__SUBAGENT_MARKER__` on subagent starts. (That marketplace also publishes `tool-search`, an MCP bridge for GPT Responses deferred tools; there is no plugin named `claude-plugin`.) `maximal app claude-code --enable` writes both `env.ANTHROPIC_BASE_URL` and `env.ANTHROPIC_API_KEY` directly into `~/.claude/settings.json` — the literal Claude Code API-client key from Settings → API clients (falling back to the default endpoint key), not an `apiKeyHelper` command. (The same key is available on demand via `maximal api claude-code`.) Details:
  - **Static value, not a re-exec'd helper.** An `apiKeyHelper` command is re-invoked by Claude Code on every request, so any drift in maximal's own path/binary (a move, a rebuild, a renamed worktree) surfaces mid-session as an opaque failure. Writing the resolved key directly has no such runtime dependency on maximal's location. `env.ANTHROPIC_API_KEY` values maximal writes are recognized by SIGNATURE (an `mxl_` prefix), not by exact match, since the key rotates across installs — see `getApiKeyOwnership` / `MANAGED_API_KEY_PREFIX` in `src/lib/auth/api-key-helper.ts` and `src/apps/claude-code/config.ts`. A legacy top-level `apiKeyHelper` field left by an older maximal version is recognized by signature too, and is always healed forward (dropped) rather than restored on disable.
  - **Takes over `ANTHROPIC_API_KEY`, but not `ANTHROPIC_BASE_URL`.** Enabling routing requires OUR key in this field to authenticate against maximal's proxy, so apply always writes it — even over a real (foreign) Anthropic key — rather than refusing (a real key left in place would just silently break routing once the base URL points at the proxy). `ANTHROPIC_BASE_URL` is treated more conservatively: a pre-existing *foreign* base URL is never overwritten, and enable refuses with a conflict surfaced in Settings → Apps.
  - **Reverts to the prior state on disable.** Toggling Claude Code off restores `env.ANTHROPIC_BASE_URL` and `env.ANTHROPIC_API_KEY` to exactly what was there before maximal first wrote them (or removes them if they were absent), via a `_maximalPrior` snapshot maximal stores in the file — so a real key that was swapped out on enable is put back on disable.
